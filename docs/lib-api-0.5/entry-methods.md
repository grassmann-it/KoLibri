# Einstiegsklassen: öffentliche Methoden und ihre Nutzung (generiert)

Stand `release/0.4.0` @ 911517b. Pro Klasse die öffentlichen Methoden; in Klammern, in welcher App der Methodenname vorkommt (C = CLI, M = MCP, D = Desktop, - = keine). Heuristik über den Namen: gleichnamige Methoden anderer Typen (`Dispose`, `RunAsync`) erzeugen falsche Treffer. Gut sichtbar sind die Alias-Paare (`Begin`/`Start`, `Preview`/`PreviewAsync`/`CreatePreviewAsync`), die 0.5 auflöst.
